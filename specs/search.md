# Todo 검색 기능 명세

## 목적

Todo가 많을 때 제목에 포함된 검색어로 필요한 Todo를 빠르게 찾을 수 있게 합니다.

## 범위

- Todo 목록에 검색창 하나를 제공합니다.
- 사용자가 검색어를 입력하면 별도의 제출 동작 없이 목록을 즉시 필터링합니다.
- Todo 제목에 검색어가 포함된 항목만 표시합니다.
- 검색은 영문 대소문자를 구분하지 않습니다.
- 검색어를 모두 지우면 전체 Todo 목록을 다시 표시합니다.

## 동작 원칙

- 검색은 화면에 표시되는 목록만 변경하며 Todo 데이터 자체를 수정하거나 삭제하지 않습니다.
- 검색 중에도 표시된 Todo의 완료/미완료 전환과 삭제 기능은 기존처럼 동작해야 합니다.
- Todo 추가 및 브라우저 저장 기능은 기존 동작을 유지합니다.
- 검색어는 브라우저에 저장하지 않습니다.

## 제외 범위

- 설명, 상태 등 제목 외 정보 검색
- 여러 검색 조건이나 고급 검색 문법
- 검색어 강조 표시
- 검색 기록 또는 검색어 저장

## 완료 조건

1. 검색창이 하나 표시된다.
2. 제목 일부를 입력하면 해당 문자열을 포함한 Todo만 즉시 표시된다.
3. 영문 대소문자가 달라도 일치하는 Todo가 표시된다.
4. 일치하는 Todo가 없으면 목록에 Todo가 표시되지 않는다.
5. 검색어를 모두 지우면 검색 전의 전체 Todo 목록이 표시된다.
6. 검색 필터링으로 Todo 데이터가 변경되지 않는다.
7. 기존 Todo 추가, 완료/미완료 전환, 삭제, 브라우저 저장 및 남은 개수 표시 기능이 유지된다.
