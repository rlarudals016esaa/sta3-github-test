# 시작시간 순 정렬 기능 명세

## 목적

사용자가 시작시간이 이른 할 일을 목록 위에서부터 시간 순서대로 확인할 수 있도록 한다.

## 사용자 시나리오

1. 사용자는 서로 다른 시작시간을 가진 할 일을 이른 시간부터 확인한다.
2. 사용자는 새 할 일을 추가하면 시작시간에 맞는 위치에 표시되는 것을 확인한다.
3. 사용자는 기존 할 일의 시작시간을 변경하거나 지우면 목록이 즉시 다시 정렬되는 것을 확인한다.
4. 페이지를 새로고침해도 같은 정렬 순서를 확인한다.

## 기능 요구사항

### 정렬 규칙

- 시작시간이 있는 할 일은 `HH:mm` 값을 기준으로 오름차순 정렬한다.
- 시작시간이 없는 할 일은 시작시간이 있는 할 일 뒤에 표시한다.
- 시작시간이 같은 할 일끼리는 기존 상대 순서를 유지한다.
- 시작시간이 없는 할 일끼리도 기존 상대 순서를 유지한다.
- 완료 상태와 우선순위는 정렬 기준에 포함하지 않는다.

### 정렬 시점

- 저장된 목록을 불러온 직후 정렬한다.
- 새 할 일을 추가한 직후 정렬한다.
- 기존 할 일의 시작시간을 변경하거나 지운 직후 정렬한다.
- 정렬된 목록 전체를 기존 `class-todo-items` localStorage 키에 저장한다.

### 기존 동작과의 관계

- 시작시간이 있는 새 할 일은 시간에 맞는 위치에 표시한다.
- 시작시간이 없는 새 할 일은 시작시간이 없는 그룹의 맨 앞에 표시한다.
- 시작시간 정렬은 `specs/start-time.md`에서 제외했던 자동 정렬을 이 기능의 범위로 추가한다.
- 제목, 완료 상태, 우선순위, 시작시간 값은 정렬 과정에서 변경하지 않는다.

## 기존 기능 유지

- 할 일 추가
- 완료/미완료 전환
- 할 일 삭제
- localStorage 저장
- 남은 할 일 개수 표시
- 우선순위 선택 및 변경
- 시작시간 지정, 변경 및 지우기

## 범위 제외

- 오름차순/내림차순 선택 UI
- 우선순위 또는 완료 상태를 함께 사용하는 다중 정렬
- 사용자가 직접 순서를 변경하는 기능
- 날짜 또는 시간대 기반 정렬
- 필터링, 검색, 알림 또는 리마인더

## 완료 조건

- [ ] 시작시간이 있는 할 일이 이른 시간부터 오름차순으로 표시된다.
- [ ] 시작시간이 없는 할 일은 시작시간이 있는 할 일 뒤에 표시된다.
- [ ] 같은 시작시간을 가진 할 일의 상대 순서가 유지된다.
- [ ] 시작시간이 없는 할 일끼리의 상대 순서가 유지된다.
- [ ] 새 할 일을 추가하면 시작시간에 맞는 위치에 표시된다.
- [ ] 시작시간을 변경하거나 지우면 목록이 즉시 다시 정렬된다.
- [ ] 정렬해도 제목, 완료 상태, 우선순위와 시작시간 값이 유지된다.
- [ ] 새로고침 후에도 같은 정렬 순서가 유지된다.
- [ ] 추가, 완료 전환, 삭제, 저장, 남은 개수 표시가 기존과 동일하게 작동한다.
- [ ] 브라우저 콘솔에 관련 오류가 발생하지 않는다.
