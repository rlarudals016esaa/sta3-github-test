# Todo 완료 상태 필터 명세

## 목적

사용자가 Todo 목록에서 전체 항목, 진행 중인 항목, 완료한 항목을 빠르게 구분해 볼 수 있도록 완료 상태 필터를 제공한다.

## 범위

- 목록에 `전체`, `진행 중`, `완료` 필터를 제공한다.
- 앱을 처음 열었을 때의 기본 필터는 `전체`이다.
- `전체`를 선택하면 완료 여부와 관계없이 모든 Todo를 표시한다.
- `진행 중`을 선택하면 미완료 Todo만 표시한다.
- `완료`를 선택하면 완료 Todo만 표시한다.
- 사용자가 선택한 필터를 화면에서 구분할 수 있어야 한다.
- 필터를 변경하면 목록에 즉시 반영한다.

## 동작 원칙

- 필터링은 Todo의 완료 상태만 기준으로 한다.
- 필터는 화면에 표시되는 목록만 변경하며 저장된 Todo 데이터는 변경하지 않는다.
- 필터가 적용된 상태에서도 기존 Todo 추가, 완료/미완료 전환, 삭제, 브라우저 저장 기능은 그대로 동작해야 한다.
- 현재 필터 조건에 맞는 Todo가 없으면 목록은 빈 상태로 표시한다.

## 완료 조건

1. 처음 진입하면 `전체`가 선택되어 있고 모든 Todo가 보인다.
2. `진행 중`을 선택하면 미완료 Todo만 보인다.
3. `완료`를 선택하면 완료 Todo만 보인다.
4. 필터를 바꾸면 별도의 새로고침 없이 표시 목록이 갱신된다.
5. 어느 필터가 선택되어 있는지 사용자가 알 수 있다.
6. 필터 사용 전후로 Todo 추가, 완료/미완료 전환, 삭제 및 브라우저 저장이 정상 동작한다.

## 제외 범위

- 선택한 필터의 브라우저 저장 또는 새로고침 후 복원
- 완료 상태 외의 기준을 사용하는 검색, 정렬 또는 추가 필터
- Todo 데이터 구조 및 저장 형식 변경
- 여러 필터의 동시 선택
